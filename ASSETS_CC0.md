## Procédure complète

1. Télécharge les SVGs dont tu as besoin (clic sur le lien → "Download SVG")
2. Dépose-les dans `scripts/tpt/themes/` avec le nom indiqué
3. Push sur GitHub → la GitHub Action génère automatiquement les packs TPT + livres KDP
4. Les ZIPs finaux apparaissent dans `products/tpt/packs/` et `products/kdp/books/`

**Avec GEMINI_API_KEY active :** tu n'as pas besoin de ces SVGs.  
Gemini génère directement les images de coloriage. Zéro téléchargement.
