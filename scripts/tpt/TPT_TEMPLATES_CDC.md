## CHARTE GRAPHIQUE COMMUNE (s'applique à TOUS les types)

```
Police principale   : Nunito (déjà dans le repo — fonts/)
Police corps        : Nunito Regular 10–11pt
Police titres       : Nunito Bold 14–17pt
Police labels       : Nunito ExtraBold 9pt

Palette de base (neutre, thème ajusté par saison) :
  Accent 1 (header)  : variable par thème (voir thèmes ci-dessous)
  Accent 2 (badges)  : version plus sombre de Accent 1
  Fond des cartes    : #FFF9F2 (crème très clair)
  Fond des boîtes    : #FFFFFF
  Texte principal    : #2C3E50 (quasi-noir)
  Texte secondaire   : #7F8C8D (gris moyen)
  Lignes/bordures    : #E0E0E0

Marges page         : 0.45 inch tous côtés
Format papier       : Letter (8.5 × 11 in)
Toujours inclure    : nom de l'auteur en pied de page + "For single classroom use only"

THÈMES & PALETTES SAISONNIÈRES :
  Halloween   : #E8771A (orange citrouille), #2C3E50 (bleu nuit)
  Christmas   : #C0392B (rouge), #27AE60 (vert forêt)
  Valentine   : #E91E8C (rose vif), #F9A8D4 (rose clair)
  Back-to-School : #2196F3 (bleu crayon), #FF9800 (orange règle)
  Spring      : #4CAF50 (vert), #FFEB3B (jaune)
  Plain/No theme  : #5B4FCF (violet éducatif), #F0EDFF (lavande clair)
```

### Images illustratives — règle d'or
- **Maximum 1 image par page**, en coin haut-droit ou bas-gauche
- **Taille** : 60–80px dans le PDF (discret, pas envahissant)
- **Style imposé** : trait noir simple, style dessin d'enfant, fond transparent (PNG)
- **Prompt universel Ideogram** :
  `simple black line drawing, children's coloring book style, cute [SUJET], white background, thick outlines, no shading, no color fill, kawaii style, minimal details`
- **Generateurs gratuits** : Ideogram.ai (recommandé) · Adobe Firefly · DALL-E ChatGPT free

## TYPE 1 — MATH FACT FLUENCY DRILLS

### Résumé
Fiches de drill timed : 50 ou 100 problèmes par fiche, format "Mad Minute".
Aucune image nécessaire — 100% chiffres.

### Structure du produit
```
Page 1      : Cover (titre, grade, opération, saison)
Pages 2–11  : 10 fiches de drill (50 ou 100 problèmes chacune)
Page 12     : Answer Key (grille des réponses)
Page 13     : Progress Tracker (graphique à compléter par l'élève)
```

```
│ [HEADER COLORÉ] Nom : _____ Date : ___      │
│                 Temps : ___ / Score : ___    │
```

## PROCHAINES ÉTAPES — ORDRE DE PRODUCTION

```

  → Générer 1 image test style "dessin d'enfant" via Ideogram
  → Valider le style visuel et la qualité

  → Refaire le générateur TYPE 1 (Math Fact Fluency) avec le nouveau CDC

  → Implémenter les autres types un par un

  → Quand 5 types validés → lancer la production en batch (10+ variants par type)

  → Upload sur TPT (manuel la première fois)
```
